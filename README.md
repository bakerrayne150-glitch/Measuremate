# MeasureMate — Home Project Calculators

Android app with 6 DIY material calculators — paint, mulch/soil/gravel, concrete, flooring, fence, and roofing — plus saved projects, shopping lists, and cost estimates.

## Tech

Flutter · Supabase (saved-project sync) · AdMob · Google Play Billing ($4.99 Pro unlock)

Package: `com.raynebaker.measurematev2`
